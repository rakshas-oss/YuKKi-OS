# YuKKi OS — Deployment Guide

---

## Prerequisites

| Tool | Minimum Version | Install |
|------|----------------|---------|
| Rust stable toolchain | 1.70+ | `rustup toolchain install stable` |
| C99 compiler | gcc 9+ / clang 12+ | System package manager |
| `cargo` | (bundled with rustup) | — |
| `zsh` | 5.8+ | System package manager (for deploy script) |

---

## v6.6.0 Sentinel Mesh — Standard Build

```bash
cd yukkios_6_6_sentinel
cargo build --release
```

Binary: `yukkios_6_6_sentinel/target/release/yukki_sentinel`

### MUSL Static Build (portable Linux binary)

```bash
rustup target add x86_64-unknown-linux-musl
cd yukkios_6_6_sentinel
cargo build --release --target x86_64-unknown-linux-musl
```

---

## v6.6.4 Apex Synthesis — Deploy Script

The v6.6.4 source tree is generated by the deployment script:

```bash
chmod +x scripts/deploy/deploy_yukki_6_6_4_apex.zsh
./scripts/deploy/deploy_yukki_6_6_4_apex.zsh
```

The script scaffolds a `yukkios_6_6_4_apex/` directory, then builds the binary:

```bash
cd yukkios_6_6_4_apex
cargo build --release
```

Binary: `yukkios_6_6_4_apex/target/release/yukki_core_node`

## Node Configuration

### Bootstrap Node

Listens for inbound peer connections on the specified address:

```bash
./yukki_sentinel bootstrap 0.0.0.0:7660
```

### Peer Node

Connect to a known bootstrap node:

```bash
./yukki_sentinel node 127.0.0.1:7660
```

---

## Command Reference

From the interactive prompt (`>`):

| Command | Description |
|---------|-------------|
| `fleet peers` | List all currently connected peer nodes |
| `msg <to> <text>` | Send encrypted `FluidMessage` to peer (node-id or `all`) |
| `weave <hex>` | Broadcast polymorphic-woven payload |
| `exit` / `quit` | Shut down the node |
