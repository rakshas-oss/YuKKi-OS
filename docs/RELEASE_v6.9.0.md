# v6.9.0 — Streaming How-To and Version Refresh

- Tag: `v6.9.0`

## Summary

This release advances the active YuKKi-OS baseline from v6.8.0 to v6.9.0.
It refreshes the README, adds a user how-to for streaming binaries and data,
and updates active release metadata and operator documentation.

The `yukki_core_node` executable name, `yukkios_6_8_0_inet3` library crate
name, and runtime protocols remain unchanged.
